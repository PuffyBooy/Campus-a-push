Zugang zu GitHub

Diese Seite steuert den Bot über die GitHub-API. Dafür braucht sie einen persönlichen Zugangsschlüssel, der nur in diesem Browser gespeichert wird (nie im Repository, nie auf einem Server).

  1. Öffne github.com → Fine-grained token.
  2. Name z. B. „Campus-Bot Steuerung“, Ablauf nach Wunsch.
  3. Repository access: „Only select repositories“ → Campus-a-push.
  4. Permissions → Repository: Actions: Read and write, Contents: Read and write, Variables: Read and write.
  5. „Generate token“ und den Schlüssel hier einfügen.
